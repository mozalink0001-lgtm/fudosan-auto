# 不動産SNS自動投稿（月額0円）

撮影した物件動画を Google ドライブに入れるだけで、次の流れが自動で進みます。

1. 動画を自動編集（縦型・30秒前後・テロップ・物件情報・LINE誘導・BGM／話している動画は字幕付き）
2. 動画から写真を切り出して、カルーセル（最大10枚）とストーリーズ画像を作成
3. 物件台帳の情報から、リール・カルーセル・Threads 用の文章を作成（禁止表現チェック、取引態様・情報時点・徒歩分数は自動表記）
4. 完成したら公式LINEに通知 → **「OK 1」と返すだけで予約**
5. 予約時刻に Instagram（リール・ストーリーズ・カルーセル）と Threads に投稿
6. 公式LINEでは、友だち追加 → 条件アンケート → 条件に合う物件の案内まで自動で返信（返信は通数無料）
7. 物件台帳で「成約」にすると、予約の取り消し・Threads投稿の削除・Instagramでアーカイブすべき投稿の通知

使うのは Google（スプレッドシート・ドライブ・Apps Script）、GitHub（動画編集と投稿の実行）、Gemini API の無料枠、各SNSの公式APIだけで、**月額の費用はかかりません**。

## 全体の仕組み

```
あなた ──撮影──▶ Googleドライブ「01_投稿待ち」
                     │（10分ごとに確認）
                     ▼
            Google Apps Script（司令塔・スプレッドシート）
              │  編集を依頼                 ▲ 完成を報告
              ▼                             │
            GitHub Actions：FFmpegで編集・Geminiで文章 ──▶ ドライブ「03_完成」
                     │
            公式LINEに通知「OK 1 で予約」◀── あなたが返信
                     │（予定時刻）
                     ▼
            GitHub Actions：素材を一時公開して Instagram / Threads に投稿 → 公開を止める
```

| 役割 | 使うもの | 費用 |
|---|---|---|
| 司令塔・台帳・LINE応答 | Google スプレッドシート＋Apps Script | 0円 |
| 素材と完成品の置き場 | Google ドライブ（15GB） | 0円 |
| 動画編集・投稿の実行 | GitHub Actions（公開リポジトリは無制限） | 0円 |
| 投稿中だけ素材を公開 | GitHub Pages | 0円 |
| 文章の生成 | Gemini API 無料枠 | 0円 |
| 文字起こし | faster-whisper（オープンソース） | 0円 |
| 投稿 | Instagram API・Threads API | 0円 |
| LINE | 公式LINE 無料プラン＋Messaging API（返信は通数に数えない） | 0円 |

> **リポジトリを「公開（Public）」にする理由**：GitHub Pages を無料で使うためと、Actions の実行時間が無制限になるためです。トークンなどの秘密の値はリポジトリに書かず、GitHub の Secrets と Apps Script の中だけに保存するので、コードが見えても問題ありません。ログにも秘密の値は伏せ字で出ます。物件の動画は投稿の数分間だけ推測できないURLで公開され、終わると消えます。

## セットアップ（最初の1回だけ・約2時間）

上から順に進めてください。各SNSのアカウントにログインするのは、あなた自身です（パスワードを誰かに渡す必要はありません）。

### 1. スプレッドシートと Apps Script（15分）

1. [Google スプレッドシート](https://sheets.new)で新しいシートを作り、名前を「SNS自動投稿」にする
2. メニュー **拡張機能 → Apps Script** を開く
3. 左の「コード.gs」の中身をすべて消して、このリポジトリの [`gas_bundle/Code.gs`](gas_bundle/Code.gs) の内容を貼り付ける
4. 左の「＋」→「HTML」で `Settings` という名前のファイルを作り、[`gas_bundle/Settings.html`](gas_bundle/Settings.html) の内容を貼り付ける
5. 💾 保存して、スプレッドシートを再読み込みする
6. メニューに出た **自動投稿 → ① 初期設定** を実行する
   - 「承認が必要です」と出たら、自分のGoogleアカウントを選んで許可します（「このアプリは確認されていません」と出たら「詳細」→「（安全でないページ）に移動」。自分で作ったスクリプトなので問題ありません）
   - Google ドライブに「SNS自動投稿」フォルダができます
7. Apps Script の画面で **デプロイ → 新しいデプロイ** → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押して、表示された **ウェブアプリのURL（…/exec）** をコピー
8. スプレッドシートで **自動投稿 → ② 設定画面を開く** → 「ウェブアプリのURL」に貼って保存

> コードを変更したときは「デプロイを管理 → 編集 → バージョン：新しいバージョン」で更新すると、URLが変わりません。

### 2. Gemini API キー（5分）

1. [Google AI Studio](https://aistudio.google.com/apikey) を開き「APIキーを作成」
2. **支払い情報は登録しない**（登録しなければ課金されることはありません）
3. キーは次の GitHub の設定で使います

> 無料枠では、入力した内容がGoogleのサービス改善に使われる場合があります。送るのは物件情報だけで、お客様の個人情報は送りません。

### 3. GitHub（20分）

1. [GitHub](https://github.com/signup) のアカウントを作る
2. 右上「＋」→ **New repository**：名前 `fudosan-auto`、**Public** を選んで作成
3. このフォルダの中身をすべてアップロードする
   - 「uploading an existing file」からフォルダごとドラッグ＆ドロップ
   - `.github` フォルダは隠しフォルダなので、Mac では Finder で `⌘ + Shift + .` を押すと表示されます
   - 空のリポジトリを作って Claude に伝えれば、こちらからアップロードすることもできます
4. リポジトリの **Settings → Pages** →「Source」を **GitHub Actions** にする
5. **Settings → Secrets and variables → Actions → New repository secret** で3つ登録

   | Name | 値 |
   |---|---|
   | `GAS_URL` | 設定画面に表示される GAS_URL |
   | `GAS_SECRET` | 設定画面に表示される GAS_SECRET |
   | `GEMINI_API_KEY` | 手順2のキー |

6. GitHub のトークンを作る：右上アイコン → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   - Repository access：**Only select repositories** → `fudosan-auto`
   - Permissions → Repository permissions → **Contents：Read and write**
   - 有効期限は最長（1年）にし、期限が来たら作り直す
7. スプレッドシートの設定画面に、リポジトリ名（`あなたのユーザー名/fudosan-auto`）とトークンを貼って保存

### 4. 公式LINE（20分）

1. [LINE公式アカウントの管理画面](https://manager.line.biz/)で、対象のアカウントを開く
2. **設定 → Messaging API → Messaging API を利用する**（プロバイダーは新規作成でOK）
3. [LINE Developers](https://developers.line.biz/console/) で、そのチャネルの **Messaging API設定** を開く
   - **チャネルアクセストークン（長期）** を発行 → 設定画面の「チャネルアクセストークン」に貼って保存
   - **Webhook URL** に、設定画面の「LINE Developers の Webhook URL に貼る値」を貼る
   - **Webhookの利用** をオン
   - 「検証」ボタンはエラーになることがありますが、Apps Script の仕様です。実際のメッセージが届けば問題ありません
4. 公式LINEの管理画面の **応答設定**
   - 応答メッセージ：**オフ**（オンだと二重に返事が出ます）
   - あいさつメッセージ：**オフ**（このシステムが代わりに送ります。文面は設定画面で変更可）
   - チャット：オンのままでOK（手動の返信もできます）
5. あなたのスマホのLINEで公式LINEを友だち追加し、設定画面に表示される **「登録 XXXXXXXX」** をそのまま送る → 「オーナーとして登録しました」と返ってくれば完了

### 5. Instagram（30分）

1. Instagram アプリで **プロアカウント（ビジネス）** に切り替える（設定 → アカウントの種類とツール）
2. [Meta for Developers](https://developers.facebook.com/apps/) で **アプリを作成**
   - ユースケース：**「Instagramでメッセージとコンテンツを管理」**
3. アプリのダッシュボード → **Instagram → APIセットアップ（Instagramログイン）**
   - 「アプリID」と「アプリシークレット」（Instagram用のもの）を設定画面に貼って保存
   - 「ビジネスログインを設定」の **リダイレクトURL** に、設定画面の「リダイレクトURI」を貼る
4. 設定画面の **「Instagram と連携する」** を押し、自分のInstagramでログインして許可
   - うまくいかない場合：APIセットアップ画面の「アカウントを追加」→「トークンを生成」で出たトークンを、設定画面の「Metaの画面で発行したトークンを貼る」に貼っても同じです
5. 「連携済み：@アカウント名」と出れば完了

> 自分のアカウントだけに投稿する使い方なら、通常はアプリ審査を受けずに「開発モード」のまま使えます。

### 6. Threads（ならし運用のあとでOK）

前回のBANを踏まえ、**新しいアカウントは最初の2〜4週間は手動で投稿**し、そのあとで自動投稿をオンにすることをおすすめします。

1. 同じ Meta アプリに、ユースケース **「Threads APIにアクセス」** を追加
2. **Threads → 設定** で「Threads アプリID」「アプリシークレット」を設定画面に貼り、「リダイレクトコールバックURL」に設定画面の「リダイレクトURI」を貼る
3. **アプリの役割 → Threadsテスター** に自分のThreadsアカウントを追加し、Threadsアプリの **設定 → アカウント → ウェブサイトのアクセス許可 → 招待** で承認
4. 設定画面の **「Threads と連携する」** を押して許可
5. ならし運用が終わったら、設定画面で **「Threads にも自動投稿する」** にチェックして保存

### 7. 自動実行をオンにする

1. スプレッドシートで **自動投稿 → ③ 自動実行をオンにする**
2. 設定画面の **「状態チェック」** で、すべて ✅ になっていることを確認

### 8. 動作テスト

1. 物件台帳にサンプルの「P001」が入っています。そのまま使えます
2. スマホで部屋を10〜30秒撮影し、ファイル名を **`P001 テスト.mp4`** にして、ドライブの「01_投稿待ち」に入れる
3. 10〜20分後に公式LINEへ「🎬 V0001 ができました」と届く
4. 届いたリンクから動画・画像を確認する。テストなので **「中止 1」** と送るか、そのまま放置（承認しなければ投稿されません）

## 毎日の使い方

1. **撮影**（撮影ルールは下記）
2. **物件台帳に1行追加**：物件ID・賃料・間取り・最寄駅・駅からの距離(m)・取引態様・おすすめポイントなど
3. **ドライブの「01_投稿待ち」に動画を入れる**
   - 1本なら：ファイル名を `P002 外観.mp4` のように **物件IDで始める**
   - 複数本なら：**物件IDの名前のフォルダ**（例 `P002`）を作って、その中に入れる（ファイル名順につながります）
   - スマホの Google ドライブアプリからアップロードできます
4. **LINEに届いた通知を見て「OK 番号」と返す**
   - 文章を直したいときは、スプレッドシートの「動画」シートの本文を直接書き換えてから OK
5. 成約したら、物件台帳の「募集状況」を **成約** にする（または LINE で「成約 P002」）

### 撮影ルール（編集の仕上がりが変わります）

- 縦向き・1080p以上・30fps
- 撮る順番：外観 → 玄関 → LDK → 水回り → 居室 → 収納 → 眺望
- 1カット5〜8秒、ゆっくり一方向に動かす
- **部屋が変わるところで1〜2秒止まる**（ここを部屋の区切りとして使い、止まった画面はカルーセルの写真になります）
- 話しながら撮ると自動で「トーク編集」（無音だけ詰めて字幕付き）。話さなければ「ツアー編集」（30秒にまとめてBGM）。物件台帳の「編集モード」で固定もできます
- 表札・郵便物・車のナンバー・近所の人が映らないように

### 投稿のスケジュール（初期設定）

| 種類 | いつ |
|---|---|
| Instagram リール | 承認後の空いている日（月〜土）の 19:00。1日1本まで |
| Instagram ストーリーズ | リールと同じ日の 19:05 |
| Threads 動画 | リールと同じ日の 20:30 |
| Instagram カルーセル | 翌日 12:15 |
| Threads 文章（部屋探しのコツ） | 翌日 7:40 |

17:30 を過ぎて承認した場合は翌日以降になります。変更は `gas/Config.gs` の `SLOTS`・`POST_DAYS` で行えます。

## LINEのコマンド

あなた（オーナー登録したLINE）から公式LINEに送ります。

| 送る文 | 動き |
|---|---|
| `OK 3` | 動画No.3 を承認し、空いている日に予約 |
| `OK 3 11/2` | 11月2日に予約（`OK 3 11/2 18:00` で時刻も指定） |
| `OK 3 今すぐ` | すぐに投稿 |
| `修正 3 冒頭を家賃からにして` | 指示を付けて作り直し |
| `中止 3` | 予約を取り消し（もう一度 OK で再予約） |
| `成約 P001` | 成約にして、予約の取り消しと投稿の整理 |
| `一覧` | 承認待ちと予約の一覧 |
| `ヘルプ` | コマンド一覧 |

お客様には、友だち追加 → 「賃貸／購入」→ エリア → 予算 → 間取り の順に自動で質問し、物件台帳で「募集中」の物件から条件に合うものを動画のURL付きで案内します。決まった質問への返事は、シート「LINE応答」で追加・変更できます。

## カスタマイズ

| 変えたいもの | 場所 |
|---|---|
| 店名・LINE ID・色・誘導文・ハッシュタグ・禁止表現 | `config/brand.json` |
| ロゴ | `assets/logo.png`（透過PNG、横長推奨）を置く |
| BGM | `assets/bgm/` に著作権フリーの mp3 を入れる |
| 動画の長さ・速さ | `config/brand.json` の `reel` |
| 投稿時刻・曜日 | `gas/Config.gs` の `SLOTS`・`POST_DAYS`（変更後は `tools/build_gas.sh` で再生成して貼り直す） |
| AIのモデル | GitHub の Settings → Variables に `GEMINI_MODEL` |
| 文字起こしの精度と速さ | Variables に `WHISPER_MODEL`（`base` は速い、`small` は標準、`off` で使わない） |

GitHub 上のファイルは、ブラウザで開いて鉛筆マークから直接編集できます。

## できないこと・注意点

- **Instagram の投稿のアーカイブ・削除・本文の編集は API でできません。** 成約時は LINE に届くURLから、アプリでアーカイブしてください（おとり広告の防止）
- **ストーリーズのリンク・アンケートのスタンプは API で付けられません。** 画像だけ自動投稿されます。スタンプを付けたい日はアプリから手動で
- **流行の音源は API で付けられません。** 著作権フリーのBGMを動画に入れる方式です
- **Threads の削除**は、設定画面で「成約時に Threads の投稿を自動で削除する」にチェックして連携し直した場合だけ自動で行います。チェックしていない場合は、LINE に削除すべきURLが届きます
- 無料枠の上限：Gemini は1日の回数、Apps Script は1日の実行時間（無料アカウントで90分）に上限があります。1日数本の運用なら十分です
- 生成された文章は広告です。最初の数週間は **必ず目で確認してから OK** してください
- InstagramとThreadsのトークンは60日で切れますが、毎日自動で延長します。延長に失敗したときは LINE に通知が来ます

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 動画を入れても何も起きない | 状態チェックが全部 ✅ か／ファイル名が物件IDで始まっているか／台帳にその物件IDがあるか／シート「ログ」 |
| 「編集に失敗」と届く | GitHub の **Actions** タブで赤くなった実行を開き、エラーを確認。`修正 番号` でやり直し |
| 投稿に失敗する | シート「投稿予定」のエラー欄。トークン切れなら設定画面から連携し直す |
| LINE が返事をしない | Webhook URL が設定画面の値と同じか／Webhookの利用がオンか／応答メッセージがオフか |
| 文章を作り直したい | `修正 番号 指示` を送るか、「動画」シートで直接書き換える |

### 手元で編集だけ試す（パソコンに ffmpeg と Python がある場合）

```bash
pip install -r requirements.txt
python -m pipeline.render --local --clips 外観.mp4 室内.mp4 --property samples/property.sample.json --out out
```

`out/` に `reel.mp4`・カルーセル画像・`story.jpg`・`captions.json` ができます。

### テスト

```bash
python -m unittest tests.test_pipeline   # 文章・投稿処理
node tests/gas_harness.js               # Apps Script の流れ（新着→承認→予約→投稿→LINE）
```
